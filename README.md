## About

This project is a frontend recreation of the **Stefanini Group** website using **React**, **Vite**, and **Tailwind CSS**.

The goal is to reproduce the original website as accurately as possible while maintaining clean, reusable, and scalable code.

This repository serves as a frontend development showcase and learning project, demonstrating modern React development practices and responsive web design.

# Getting Started

## Clone Repository

```bash
git clone https://github.com/ravipcats/stefaninii.git
```

## Navigate

```bash
cd stefaninii
```

## Install Packages

```bash
npm install
```

## Run Development Server

```bash
npm run dev
```

Open

```
http://localhost:5173
```
